02 / CRIMPING

Cara Crimping Kabel LAN

Urutan praktik mengikuti materi: potong, kupas, susun, masukkan RJ45, crimping, lalu uji.

01

Potong kabel

Potong kabel UTP sesuai kebutuhan.

02

Kupas kabel

Kupas bagian luar kabel sekitar 2–3 cm.

03

Pisahkan 8 kabel

Pisahkan delapan kabel kecil di dalamnya.

04

Susun T568A

Susun kabel sesuai T568A untuk ujung pertama.

05

Rapikan

Luruskan kabel dan potong rata supaya semua ujung sama panjang.

06

Masukkan RJ45

Pastikan semua kabel masuk sampai ujung konektor.

07

Crimping

Masukkan RJ45 ke tang crimping lalu tekan sampai konektor terkunci.

08

Ujung kedua T568B

Ulangi proses pada ujung kedua menggunakan T568B.


💡 Setelah selesai, gunakan LAN cable tester. Urutan lampu ideal: 1 → 2 → 3 → 4 → 5 → 6 → 7 → 8. Jika lampu tidak menyala atau urutannya salah, kabel perlu diperiksa dan dapat di-crimp ulang.

04 / NETWORK

Menghubungkan 2 Laptop

Gunakan kabel LAN yang sudah selesai dirakit untuk menghubungkan kedua laptop.

01

Hubungkan kabel

Hubungkan kedua ujung kabel LAN ke port Ethernet masing-masing laptop. Pastikan kabel terpasang dengan benar.

02

Buka Control Panel

Start → Control Panel → Network and Sharing Center → Change adapter settings.

03

Atur IPv4

Klik kanan Ethernet → Properties → Internet Protocol Version 4 (TCP/IPv4) → Properties → Use the following IP address.

04

Simpan

Masukkan konfigurasi IP sesuai tabel, kemudian klik OK.


PengaturanLaptop 1Laptop 2
IP Address192.168.1.1192.168.1.2
Subnet Mask255.255.255.0255.255.255.0
05 / TEST

Pengecekan Keterhubungan

Uji koneksi menggunakan Command Prompt.

01

Buka CMD

Tekan Windows + R, ketik cmd, lalu tekan Enter.

02

Laptop 1 → Laptop 2

ping 192.168.1.2
03

Laptop 2 → Laptop 1

ping 192.168.1.1
04

Periksa hasil

Jika muncul tulisan Reply from, berarti kedua laptop berhasil terhubung melalui jaringan LAN.

06 / FILE SHARING

Sharing File via LAN

Setelah koneksi berhasil, folder dapat dibagikan dari Laptop 1 dan diakses Laptop 2.

01

Pilih folder

Pilih folder yang ingin dibagikan di Laptop 1.

02

Aktifkan sharing

Klik kanan folder → Properties → Sharing → Advanced Sharing → Share this folder → Apply.

03

Akses dari Laptop 2

Tekan Windows + R lalu masukkan alamat:

\\192.168.1.1
04

Transfer file

Jika folder tampil, buka dan lakukan copy/paste sesuai izin akses.
